# 🐳 Управление инфраструктурой (Docker & k3d)

## 📌 Статус и проверка окружения
Проверить запущенные контейнеры (узлы кластера) в Docker:
```bash
docker ps
```

Посмотреть список существующих локальных кластеров:
```bash
k3d cluster list
```

## 🔋 Экономия ресурсов Mac M5 (Пауза/Старт)
Остановить кластер (заморозить виртуальные серверы, освободить RAM):
```bash
k3d cluster stop sandbox
```

Запустить замороженный кластер обратно:
```bash
k3d cluster start sandbox
```

## 🧹 Полная очистка песочницы
Удалить кластер полностью (все поды и настройки внутри сотрутся):
```bash
k3d cluster delete sandbox
```

Создать кластер заново по декларативному конфигу:
```bash
k3d cluster create --config cluster-config.yaml
```
