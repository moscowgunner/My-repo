# ☸️ Оркестрация и Траблшутинг (Kubernetes & k9s)

## 🎛️ Запуск диспетчерской панели k9s

Запустить k9s (клиент управления):
```bash
k9s
```

### ⌨️ Горячие клавиши внутри k9s:
* `:` (двоеточие) — открыть строку ввода команд.
* `:po` — перейти к списку **Подов** (Pods).
* `:no` — перейти к списку **Узлов** (Nodes — Сервер и Агенты).
* `:deploy` — перейти к списку **Деплойментов** (Deployments).
* `0` (ноль) — показать ресурсы во **всех** пространствах имен (Namespaces).
* `l` (на поде) — открыть **логи** контейнера в реальном времени (`Esc` — выйти).
* `s` (на поде) — провалиться внутрь контейнера через **консоль Shell** (`exit` — выйти).
* `d` (на ресурсе) — детальное описание **Describe** и просмотр системных ошибок/событий.
* `e` (на ресурсе) — редактировать YAML-манифест «на лету» через Vim.
* `Ctrl + D` — принудительно удалить (пристрелить) выбранный Под.

## 🛠️ Базовые команды kubectl (для консоли)
Посмотреть статус всех физических/виртуальных серверов кластера:
```bash
kubectl get nodes
```

Посмотреть поды в пространстве по умолчанию (default):
```bash
kubectl get pods
```

Принудительное жесткое удаление зависшего пода (Force Delete):
```bash
kubectl delete pod <имя_пода> -n <неймспейс> --force --grace-period=0
```
