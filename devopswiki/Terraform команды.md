1. Подготовка и инициализация

- `terraform init`
    - **Что делает:** Инициализирует рабочую директорию. Скачивает провайдеры (плагины), указанные в `main.tf`, используя ваше локальное зеркало (`~/.terraformrc`). Создает скрытую папку `.terraform/` и файл блокировки версий `.terraform.lock.hcl`.
    - _Когда запускать:_ Самый первый раз при создании проекта или при добавлении новых провайдеров/модулей.
- `terraform validate`
    - **Что делает:** Проверяет синтаксис конфигурационных файлов на корректность и наличие внутренних ошибок. При этом она не пытается связаться с реальной инфраструктурой.
- `terraform fmt`
    - **Что делает:** Автоматически форматирует все файлы конфигурации (`.tf`) в вашей папке по официальному стандарту (выравнивает отступы, скобки и знаки равенства).

2. Управление жизненным циклом инфраструктуры

- `terraform plan`
    - **Что делает:** Генерирует и показывает план изменений. Сравнивает текущую конфигурацию в коде с реальным состоянием вашей инфраструктуры (в вашем случае — контейнерами в OrbStack) и выводит список того, что будет создано (`+`), изменено (`~`) или удалено (`-`).
- `terraform apply`
    - **Что делает:** Применяет изменения и разворачивает инфраструктуру. Перед стартом еще раз показывает план и запрашивает ручное подтверждение (нужно ввести `yes`).
- `terraform apply -auto-approve`
    - **Что делает:** То же самое, что и `apply`, но пропускает интерактивный запрос `yes`. Полезно для автоматизации (например, внутри пайплайнов GitLab CI / GitHub Actions).
- `terraform destroy`
    - **Что делает:** Полностью уничтожает всю инфраструктуру, описанную в текущем проекте. Перед удалением также запрашивает подтверждение `yes`.

3. Работа с состоянием (State)

> [!warning] Важно  
> Файл `terraform.tfstate` — это «сердце» вашего проекта. Не редактируйте его вручную! Для управления состоянием используйте специальные команды ниже.

- `terraform state list`
    - **Что делает:** Выводит список всех ресурсов, которые сейчас находятся под управлением текущего Terraform-проекта и записаны в файл `.tfstate`.
- `terraform show`
    - **Что делает:** Показывает подробную, удобочитаемую информацию о текущем состоянии всех развернутых ресурсов со всеми их внутренними атрибутами (IP-адреса, ID контейнеров, маппинг портов).
